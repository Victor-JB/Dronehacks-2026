# sim/

Run everything with `./fly-sim.sh` at the repository root (see the README there).

| Path | What | From |
|---|---|---|
| `skybeta/` | the drone stack in the sim | this repo |
| `models/skybeta` | the Sky Beta airframe (generated by `skybeta/make_model.py`) | this repo |
| `worlds/course.sdf`, `models/course_v3`, `assets/` | the DroneHacks course | [machmoon/dronehacks-sim](https://github.com/machmoon/dronehacks-sim) `codex/markerfree-flight` @ 96a1641 |
| `models/flight_x500*` | PX4's x500, the base `skybeta/make_model.py` edits | same |
| `vision/scene.py`, `vision/course.py` | builds the world file around the launch mark | same |
| `Dockerfile`, `Dockerfile.px4`, `px4/`, `runtime/start.sh` | the Gazebo image and the PX4 v1.16.2 SITL build | same |
